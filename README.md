## Бизнес-логика приложения

Консольное приложение для нахождения маршрутов из любого города России до любого другого города, с использованием Yandex API, внешние библиотеки и кэширование.

## Функционал приложения

Консольное приложение ищет список возможных маршрутов из между двумя любыми городами туда и обратно, любыми видами транспорта (например, самолёт + поезд) на определённую дату и с определенным количеством пересадок (дата и кол-во пересадок передаются аргументами командной строки).  
Найденные промежуточные результаты кэшируются для уменьшения количества запросов к внешнему сервису.

Программа имеет интерактивный режим, для обработки более 1 запроса пользователя за 1 запуск. 

## Источник данных

В качестве источника информации было использовано [API Яндекс Расписаний](https://yandex.ru/dev/rasp/doc/ru/).  

## Реализация
  
Для выполнения HTTP-запросов использована библиотека [C++ Requests](https://github.com/libcpr/cpr).
В качестве библиотеки для работы с JSON-ответом использован [nlohmann/json](https://github.com/nlohmann/json).

## Кэширование

В данной работе рееализовано LRU кэширование ответов Яндекс Расписаний для уменьшения нагрузки и выполнения ограничений со стороны сервиса.  

## Тестирование

Сущности данной работы покрыты unit тестами с помощью фреймворка gtest, сетевые походы замоканы с помощью gmock.
